# 実装状況

更新日：2026-09-08。実装版：0.1.0。

## 実装済み

ドット描画エンジン、13種類のコマンド、レイヤー構成・ロック・表示・不透明度、原稿スナップショット、一括操作、revision競合、セッション内再送排除、Undo/Redo、日本語UI、ドラッグプレビュー、PNG/原稿出力、原稿読込、ブラウザ内自動保存、JSON操作、検証付きサンプルジョブ、Playwright自動描画スクリプトを実装しています。

GitHub ActionsのCI定義と、仕様・進捗・引き継ぎ文書を追加しています。CIは読み取り権限でテストし、成果物をActions artifactへ出す構成です。これは素材の別リポジトリ格納機能ではありません。

## ローカル検証

Node.js v22.16.0でコアテスト27件が成功しました。描画、透過、レイヤー、ロック、競合、原子性、再送、Undo/Redo、原稿往復、入力拒否、上限、ジョブの再現性を含みます。

通常のHTTPブラウザ統合試験10件は、この作業環境のChromiumがページ遷移を管理ポリシーで拒否したため実行成立していません。アプリの試験失敗とは別の環境ブロックですが、成功扱いにはしていません。

代わりにネットワークを使用せず、同じHTML/CSS/JavaScriptをブラウザ内へ渡すオフライン確認を実施しました。画面起動、ポインター描画、Undo/Redo、サンプルジョブ、PNG生成、転送ハッシュ一致、デスクトップ/モバイル画面の取得に成功しています。この確認では原点のないページ向けにstorage・fetch・WebCryptoの一部をテスト用に置き換えているため、CSP、HTTP配信、GitHub Pages、永続ストレージの受入試験を代替しません。

実際のGitHub Actionsの実行結果、GitHub Pagesの公開結果は別途確認します。未実行の項目や環境ブロックを緑に塗り替えないでください。

## 次の到達点

HTTPブラウザ試験とCIの成功確認、Pages公開確認を行います。その後、素材リポジトリBを指定し、固定アプリ版の取得、ジョブ受付、描画と公開の権限分離、PR保存、読み戻し検証を実装します。PNGを作れたことだけで当初目的の全体完成とはしません。
